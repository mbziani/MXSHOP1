Présentation du Projet : MX Shop E-commerce de d’équipements motocross

*Introduction générale :

MX Shop c’est un boutique e-commerce de vêtements de motocross que j'ai développée avec Laravel. J'ai choisi SQLite comme base de données, ce qui rend l'installation très simple. Le site permet aux utilisateurs de parcourir les produits par catégorie, voir les détails de chaque article, et gérer leur panier d'achat de manière dynamique. J'ai utilisé AJAX pour la mise à jour des quantités dans le panier. Le code respecte parfaitement la structure Laravel avec des contrôleurs, des modèles Eloquent, des migrations et des vues Blade. Le projet est versionné sur GitHub et peut être installé en quelques commandes.

*Introduction :

MX Shop est une boutique en ligne développée avec Laravel pour vendre des vêtements et équipements de motocross.

*Fonctionnalités principales :

Catalogue produits, filtres par catégorie, pages détail, panier dynamique, design responsive, interface moderne.
